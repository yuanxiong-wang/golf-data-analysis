Golfstat Junior Golf Analysis

Turning public junior golf results into a repeatable scouting dataset.

This report summarizes the first working data pipeline for Golfstat's Junior Golf and high-school leaderboard coverage: source discovery, raw snapshots, parsed event records, current leaderboards, and analysis-ready CSV outputs.

  • Source: Golfstat homepage and Junior event list

Executive Summary

The project now has a reproducible path from Golfstat public pages to structured datasets. The Junior Golf section is broad enough for trend tracking: 172 archive events were parsed across 2002-2025, while the current homepage exposure covers 11 active tournament IDs with player and team leaderboards where available.

Recommended use: keep the repository private for stakeholder review because the dataset contains junior-player names and scores, even though the source pages are public.

Data Pipeline

The pipeline preserves source evidence first, then derives analysis tables. This makes the work auditable: each CSV points back to source HTML snapshots under raw/.

The current scripts are intentionally simple Python parsers so the analysis can be rebuilt and reviewed without a database or external service.

1

Read Golfstat homepage miniboard links and Junior Golf event-list pages.
2

Store raw HTML pages for event lists, miniboards, player boards, and team boards.
3

Convert source pages into CSVs for archive events, homepage boards, leaders, and full results.
4

Analyze

Generate Markdown and HTML reports that surface coverage, leaders, caveats, and next steps.

Quality Notes

The parsed CSVs preserve both the displayed total and the visible round-score sum. One row currently has a mismatch between those values, which appears to come from the source page itself rather than the parser. This is useful: the dataset can flag scoring anomalies without silently correcting them.

Rows checked 592
Visible total mismatch 1

The next quality step is to add automated checks for duplicate player names within an event, missing round values, stale homepage links, and player/team board availability.

GKZID Growth Targeting Layer

GKZID already has early proof: the platform reported more than 15,320 cards/users in its first month, and the live homepage counter observed during this review shows 15,479+ cards built. The junior golf dataset gives that traction a sharper wedge: real athlete achievement moments where a player card, identity page, or verified profile has a natural reason to be shared.

Use the Golfstat data for segment selection, content themes, event timing, and aggregate insights. Do not scrape contact details or mass-message minors. The strongest growth motion is opt-in sharing through athletes, parents, coaches, teams, and event communities.

Best Initial Audience Wedges

  • Leaderboard moment pages Create social posts and landing pages around public results: "You made the board. Now build the card that tells the story."
  • Team roster kits Target WIAA and Toyota team events with coach-friendly roster card packs, not one-off individual signups.
  • Parent share loops Parents are natural distributors for junior achievements. Give them simple share copy, card examples, and milestone templates.
  • Verified athlete pathway Use VAN as the trust layer: a badge is more viral when athletes understand how to earn, display, and share it.
